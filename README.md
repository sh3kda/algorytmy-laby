# Algorytmy i Struktury Danych - Laby

Repozytorium zawiera implementacje struktur danych oraz algorytmów

```Zakres materiału

├── 01_zlozonosc_obliczeniowa/      # Analiza asymptotyczna (notacja O, Omega, Theta)
├── 02_sortowanie/                  # Algorytmy elementarne oraz zaawansowane
│   ├── elementarne/                # Insertion Sort, Selection Sort, Bubble Sort
│   └── zaawansowane/               # QuickSort, MergeSort, HeapSort, Counting Sort
├── 03_listy/                       # Implementacja wskaźnikowa i kursorowa
├── 04_stosy_i_kolejki/             # LIFO, FIFO oraz kolejka priorytetowa (kopiec binarny)
├── 05_drzewa/                      # Drzewa binarne (BST), porządki przejścia (pre/in/post-order)
├── 06_grafy_podstawy/              # Reprezentacje grafów (macierz, listy), przeszukiwanie BFS/DFS
├── 07_algorytmy_grafowe/           # Najkrótsze ścieżki (Dijkstra) oraz cykl Eulera
├── 08_slowniki/                    # Tablice z haszowaniem (otwarte/zamknięte), funkcje skrótu
└── 09_wyszukiwanie_wzorca/         # Algorytmy tekstowe: Morrisa-Pratta (MP), KMP, Boyera-Moore'a (BM)
```
